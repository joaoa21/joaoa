Kompres.

Imagens prontas para a web.

Um site para comprimir e converter imagens em lote, com controle de qualidade e download em ZIP.

Acessar o sitekompres.com.br ↗

01 — O PROJETO

Nasceu de uma necessidade real.

O Kompres surgiu na rotina do time de CRM em iGaming, para acabar com a conversão manual de PNG para WebP antes de publicar cada banner. Ele reúne a preparação das imagens num fluxo direto no navegador, da seleção dos arquivos ao download, e é usado por mim e pela equipe para acelerar as entregas.

Categoria
Site / aplicação web
Desenvolvimento
HTML · CSS · JavaScript
Uso
Rotina do time de CRM

02 — A EXPERIÊNCIA

Um fluxo simples, do início ao fim.

/01

Adicionar

Arraste suas imagens para começar uma conversão em lote.

/02

Ajustar

Escolha o formato de saída — WebP, PNG ou JPEG — e ajuste a qualidade.

/03

Baixar

Reúna os arquivos convertidos em um ZIP para usar no seu projeto.
