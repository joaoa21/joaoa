Questions

Common questions.

How much does a website cost?

It depends on the size of the project and what the website needs to do. After a quick conversation, I send a proposal with scope, timeline and price agreed before we start.

How long does it take to build a website?

It varies from project to project. A landing page is usually faster than a multi-page website. The timeline is set in the proposal, before we start.

Do you work with clients outside Brazil?

Yes. I work from Recife, Brazil (UTC−3), and the whole process can happen online, wherever you are.

Will my website show up on Google?

Every website ships with the SEO basics in place: titles and descriptions, a sitemap, optimized performance and Google Search Console set up. Search ranking also depends on content and time.

Will I be able to update the website later?

It depends on the project: we can include a panel for you to edit text and images, or agree on updates with me. This is defined in the proposal.

Do you also create the visual identity?

Yes. I come from art direction and branding, so we can create the brand and the website together, with the same visual language.
